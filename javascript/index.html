La regla que resuelve todos estos ejercicios
1 · PilaTodo el código sincrónico, de arriba abajo. Incluye el cuerpo de new Promise(...) y el de una función async hasta su primer await.
2 · Microtareas.then, .catch, .finally, lo que sigue a un await y queueMicrotask. Se vacía la cola entera, incluso lo que se agrega mientras tanto.
3 · Una macrotareasetTimeout, setInterval, eventos del DOM, I/O. Corre una sola y se vuelve al paso 2.

      Variables

      const PI = 3.14;   // no se reasigna (usala por defecto)
let total = 0;     // se puede reasignar
total += 10;
// var: scope de función y hoisting. No se usa más.

      const no hace inmutable al objeto: const u = {}; u.nombre = 'Leo' es válido. Lo que no podés es reasignar u.

      Arrow functions

      const doble = (n) => n * 2;            // return implícito
const sumar = (a, b) => {              // con llaves: return explícito
  return a + b;
};
const crear = (nombre) => ({ nombre }); // objeto: entre paréntesis

      No tienen this propio ni arguments, y no se usan con new.

      Strings, defaults, rest y spread

      const saludo = `Hola, ${nombre}!`;        // template literal
const f = (nombre = 'invitado') => nombre; // parámetro por defecto
const sumarTodo = (...nums) => nums.reduce((a, n) => a + n, 0); // rest
const copia = [...lista, 4];              // spread de array
const nuevo = { ...usuario, edad: 31 };   // spread de objeto

      Destructuring

      const { nombre, edad = 0 } = usuario;     // con valor por defecto
const { address: { city } } = usuario;    // anidado
const [primero, , tercero] = lista;       // saltea el segundo
const [valor, setValor] = useState(0);    // así se usa en React
const presentar = ({ nombre }) => nombre; // en parámetros

      Arrays

      lista.map((x) => x * 2);          // transforma: array nuevo
lista.filter((x) => x > 0);       // filtra: array nuevo
lista.reduce((acc, x) => acc + x, 0); // acumula en un valor
lista.find((x) => x.id === 3);    // el primero o undefined
lista.some((x) => x.activo);      // ¿alguno cumple?
lista.every((x) => x.activo);     // ¿todos cumplen?
lista.includes(3);                // ¿está?

      Ninguno de estos modifica el array original. sort, push y splice sí lo modifican.

      Objetos

      const u = { nombre, edad };          // shorthand
u?.direccion?.ciudad;                // optional chaining: undefined si falta
const limite = config.limite ?? 10;  // ?? solo reemplaza null/undefined
Object.keys(u);    // [ 'nombre', 'edad' ]
Object.entries(u); // [ [ 'nombre', 'Leo' ], [ 'edad', 30 ] ]

      ?? contra ||: con 0 o '', || usa el valor por defecto y ?? no.

      Promesas

      const p = new Promise((resolve, reject) => {
  // el executor corre en el acto
  ok ? resolve(valor) : reject(new Error('falló'));
});

p.then((v) => console.log(v))
  .catch((e) => console.error(e.message))
  .finally(() => console.log('siempre'));

      Estados: pendiente → cumplida o rechazada. Una vez asentada, no cambia más.

      Combinar promesas

      await Promise.all([a, b]);        // todas, o falla con la primera que rechace
await Promise.allSettled([a, b]); // todas, con { status, value | reason }
await Promise.race([a, b]);       // la primera que se asiente
await Promise.any([a, b]);        // la primera que se cumpla

      async / await

      async function cargar(id) {
  try {
    const usuario = await api.getUser(id); // pausa esta función, no el programa
    return usuario.name;                   // resuelve la promesa
  } catch (error) {
    throw new Error('No se pudo cargar');  // rechaza la promesa
  }
}

// Secuencial (uno espera al otro) contra paralelo
const a = await pedir(1); const b = await pedir(2);
const [c, d] = await Promise.all([pedir(1), pedir(2)]);

      fetch

      const res = await fetch('/api/turnos', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ fecha: '2026-09-28' })
});
if (!res.ok) throw new Error('HTTP ' + res.status); // 404 y 500 no rechazan
const data = await res.json();
