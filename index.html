practicing-for-interview

Tomé los requisitos de una búsqueda de programador full-stack, marqué lo que tenía flojo y armé herramientas propias para practicarlo. Cada módulo se usa directo en el navegador, sin instalar nada.

Módulos

  • listo Linux · Dojo de terminal Simulador de Ubuntu con sistema de archivos, pipes, permisos, procesos y nano. 20 misiones guiadas, chuleta y preguntas de entrevista.
  • listo JavaScript ES6+ · Dojo de JavaScript 12 ejercicios de event loop que corren el código real, 14 katas con tests (arrow functions, promesas, async/await, fetch), playground, guía rápida y preguntas de entrevista.
  • en colaReactProps, estado, hooks y análisis de código.
  • en colaSQLJOINs, claves foráneas y agregaciones.
  • en colaAPIs REST y JSONVerbos, códigos de estado, idempotencia.
  • en colaGitBranch, merge vs rebase, pull requests.
  • en colan8nWebhook → base de datos → respuesta JSON.
