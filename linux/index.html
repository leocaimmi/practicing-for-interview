    Lo que te pueden preguntar

    ¿Ruta absoluta vs relativa?

    Absoluta arranca en la raíz / y funciona desde cualquier lado (/home/leo/docs). Relativa depende de dónde estás parado (docs, ../x).

    ¿Qué diferencia hay entre > y >>?

    > crea o pisa el archivo. >> agrega al final sin borrar lo anterior. Típico: echo "x" >> log.txt.

    ¿Qué es un pipe?

    Conecta la salida estándar de un comando con la entrada del siguiente: ps aux | grep node. Es la filosofía Unix: herramientas chicas que se combinan.

    ¿Qué significa chmod 755?

    Cada dígito suma r=4, w=2, x=1. 7 = rwx para el dueño, 5 = r-x para grupo y otros. Es lo típico para scripts y carpetas. Archivos comunes: 644.

    ¿Cómo ejecutás un script?

    Le das permiso con chmod +x deploy.sh y lo corrés con ./deploy.sh. El ./ hace falta porque la carpeta actual no está en el PATH. La primera línea #!/bin/bash (shebang) dice qué intérprete usar.

    ¿Qué es sudo y por qué apt lo pide?

    Ejecuta un comando como root (superusuario). Instalar paquetes escribe en carpetas del sistema como /usr, que tu usuario no puede tocar.

    ¿rm -r vs rmdir?

    rmdir solo borra carpetas vacías (más seguro). rm -r borra la carpeta con todo adentro. rm -rf además no pregunta ni avisa: con cuidado.

    ¿Cómo encontrás y matás un proceso colgado?

    ps aux | grep node para ver el PID, después kill PID (SIGTERM, le pide que cierre prolijo). Si no responde, kill -9 PID (SIGKILL, lo corta en seco). También lsof -i :3000 para ver quién usa un puerto.

    ¿Cómo buscás algo en todo un proyecto?

    Texto adentro de archivos: grep -rn "TODO" src/. Archivos por nombre: find . -name "*.js".

    ¿Cómo mirás un log en vivo?

    tail -f /var/log/syslog o el log de tu app. Sale con Ctrl+C. En servicios con systemd: journalctl -u servicio -f.

    ¿stdout vs stderr?

    Son dos salidas distintas: 1 = salida normal, 2 = errores. cmd 2> errores.txt redirige solo errores; cmd > todo.txt 2>&1 manda ambos al mismo archivo.

    ¿Cómo ves variables de entorno?

    echo $HOME, env para ver todas, export API_URL=... para definir una en la sesión. Así se pasan secretos a una app sin hardcodearlos.
